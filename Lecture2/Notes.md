## Common Mistakes:
1. Multiple scaling
2. Too much information
3. Cryptic infromation
4. Missing values
5. Using the wrong type of graph
6. Using tricks to manipulate the results
 
## Principles:
1. **Occam's Rezor**: If two representations contain the same information, choose the simpler one.
2. **Completion(Dijkstra)**:When you cannot remove any simple object from the representation, then it is complete.
3. **Common sense**: Use an adapted sophistication level.
